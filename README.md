# LaTeX Field Guide

A practical, interactive introduction to LaTeX for technical reports, equations, figures, tables, and research papers, written for engineering students and researchers.

## Live tool

[Open LaTeX Field Guide](https://nuhaaljuneidi.github.io/latex-guide/)

## Features

- Seven-step learning path with progress tracking: first document, document structure, equations, figures and tables, citations, fixing compilation errors, and a pre-submission checklist.
- Equation playground for trying LaTeX math and seeing it rendered.
- Heat-transfer examples (Fourier's law, conduction resistance) used throughout.

## Run locally

Open `index.html` in a modern browser. No build step is needed.

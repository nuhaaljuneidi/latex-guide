01 — FOUNDATIONS

Your first document

Every LaTeX document has a preamble for settings and a document environment for content. Start with this minimal, dependable structure.

The essential skeleton

Choose a document class, load packages, then place visible content between \begin{document} and \end{document}.

\documentclass[11pt]{article} \usepackage[margin=1in]{geometry} \usepackage{amsmath} \title{My Technical Report} \author{Your Name} \date{\today} \begin{document} \maketitle \section{Introduction} This is my first LaTeX document. \end{document}
Use Overleaf for a zero-install start, or TeX Live/MiKTeX with an editor for local work.
CommandsBegin with a backslash: \section{...}
CommentsAnything after % is ignored.
GroupsCurly braces contain command arguments.
CompileYour .tex source becomes a PDF.
02 — ORGANIZATION

Structure the story

Good technical writing uses hierarchy consistently. Let LaTeX number and format the document for you.

Sections, emphasis, and lists

\section{Methods} \subsection{Experimental Setup} The \textbf{primary objective} is to evaluate \emph{thermal performance}. \begin{enumerate} \item Define the boundary conditions. \item Run the simulation. \item Validate the results. \end{enumerate}

03 — MATHEMATICS

Typeset equations

Mathematics is LaTeX’s natural habitat. Use inline math for short expressions and displayed environments for important equations.

Inline and displayed math

The Reynolds number is $Re = \rho V D / \mu$. \begin{equation} \eta = \frac{Q_{delivered}}{Q_{demand}} \label{eq:efficiency} \end{equation} As shown in Equation~\ref{eq:efficiency}, ...
Label equations, figures, tables, and sections. Refer to the label—not a number typed by hand.

04 — EVIDENCE

Present results clearly

Treat every visual as part of your argument: place it, caption it, label it, and discuss it in the text.

A publication-ready figure

\usepackage{graphicx} \begin{figure}[htbp] \centering \includegraphics[width=0.78\textwidth]{results.png} \caption{Temperature evolution during solidification.} \label{fig:temperature} \end{figure}

A clean table

\usepackage{booktabs} \begin{table}[htbp] \centering \caption{Model performance metrics.} \label{tab:metrics} \begin{tabular}{lcc} \toprule Model & RMSE & $R^2$ \\ \midrule Random Forest & 0.041 & 0.96 \\ Gaussian Process & 0.035 & 0.97 \\ \bottomrule \end{tabular} \end{table}
05 — SOURCES

Manage citations

Keep references in a separate BibTeX file. One source record can then be cited, reordered, and restyled automatically.

Bibliography workflow

% references.bib @article{aljuneidi2024thermal, author = {Aljuneidi, Nuha and Others}, title = {Thermal Energy Storage Review}, journal = {Advances in Heat Transfer}, year = {2024} } % main.tex Thermal storage has been widely studied \cite{aljuneidi2024thermal}. \bibliographystyle{plain} \bibliography{references}
For modern projects, consider biblatex with biber; follow the template required by your journal or conference.
